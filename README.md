# 진원이 송별회 초대장 + 참석 여부(RSVP)

2026년 10월 1일(목) 송별회 초대장과 참석 여부를 받는 모바일 사이트입니다.
정적 HTML/CSS/JS로 되어 있고, 응답은 Google Sheets에 저장됩니다(Apps Script 웹 앱).

| 파일 | 역할 |
|---|---|
| `index.html` | 초대장 |
| `rsvp.html` | 참석 여부 응답 폼 |
| `done.html` | 응답 완료 화면 |
| `admin.html` | 주최자용 응답 현황 (`?key=` 필요) |
| `config.js` | **시간·장소 등 설정값. 이 파일만 고치면 모든 페이지에 반영됩니다** |
| `common.js`, `style.css` | 공용 스크립트·스타일 |
| `apps-script/Code.gs` | Google Apps Script 백엔드 코드 |
| `images/` | 최적화한 사진(가로 1080px, 위치정보 제거) + 카톡 미리보기용 `og.jpg` |

> 루트에 있는 원본 사진과 디자인 PDF는 `.gitignore`로 배포에서 빠집니다(원본 사진에는 GPS 위치정보가 있습니다).

## 1. Google Sheets + Apps Script 설정 (한 번만)

1. **개인 gmail 계정**으로 Google Sheets에서 새 스프레드시트를 만듭니다.
   (학교·회사 계정은 '모든 사용자' 공개가 막혀 있을 수 있습니다.)
2. 시트 메뉴 **파일 > 설정 > 시간대**를 `(GMT+09:00) 서울`로 바꿉니다.
3. 시트 메뉴 **확장 프로그램 > Apps Script**를 엽니다.
   기본 `Code.gs` 내용을 지우고 이 저장소의 `apps-script/Code.gs`를 통째로 붙여 넣은 뒤 저장(Ctrl+S)합니다.
4. 왼쪽 **⚙ 프로젝트 설정 > 스크립트 속성 > 스크립트 속성 추가**
   - 속성: `ADMIN_KEY`
   - 값: 영문과 숫자만으로 된 16자 이상의 임의 문자열 (다른 사람이 짐작할 수 없게)
   - 이 값은 나중에 바꿔도 다시 배포할 필요가 없습니다.
5. 오른쪽 위 **배포 > 새 배포**
   - 유형 선택(⚙): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
     (**'Google 계정이 있는 모든 사용자'가 아닙니다.** 이걸 고르면 카톡에서 여는 사람들의 응답이 전부 실패합니다.)
6. 권한 승인 화면에서 **'Google에서 확인하지 않은 앱'**이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**을 누릅니다. 내가 만든 스크립트라서 나오는 정상 화면입니다.
7. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해 `config.js`의 `apiUrl`에 넣습니다.
   - `/exec`로 끝나야 합니다. `/dev` 주소는 로그인한 본인만 쓸 수 있어서 안 됩니다.

응답이 처음 들어오면 스크립트가 `responses` 시트를 만들고 헤더(`name | first | second | message | createdAt | updatedAt`)를 붙입니다.

### Code.gs를 고친 경우

**배포 > 배포 관리 > ✏ 편집 > 버전: 새 버전 > 배포** 순서로 올립니다. 이렇게 하면 URL이 그대로 유지됩니다.
코드를 저장만 하면 웹 앱에는 반영되지 않습니다. '새 배포'를 다시 누르면 URL이 새로 생기므로 누르지 마세요.
(실수로 눌렀다면 새 URL을 `config.js`의 `apiUrl`에 넣으면 됩니다.)

## 2. 설정값 채우기 (`config.js`)

아직 정해지지 않은 값은 `''`(빈 값)로 두면 초대장에 **'추후 공지'**로 나오거나 그 항목이 숨겨집니다.
정해지는 대로 채우고 다시 올리면 모든 페이지에 반영됩니다.

| 항목 | 형식 / 예시 | 비어 있을 때 |
|---|---|---|
| `firstTime` | 24시간 `'19:00'` → 초대장에 '오후 7:00 1차 시작' | '시간 추후 공지', 캘린더는 종일 일정 |
| `firstPlace` | `'○○고기집 역삼점'` | '장소 추후 공지' |
| `firstAddress` | 상세 주소 | 주소 줄·'주소 복사' 버튼 숨김 |
| `mapUrl` | 네이버/카카오 지도 앱 **공유 → 링크 복사** 주소 (`https://naver.me/...`, `https://kko.to/...`) | '지도 앱으로 보기' 버튼 숨김 |
| `mapEmbedUrl` | PC에서 구글 지도 > 장소 검색 > **공유 > 지도 퍼가기** > HTML 복사 후 `src="..."` **따옴표 안의 주소만** | 지도 영역 숨김 |
| `secondPlace`, `secondTime` | `'○○호프'`, `'21:30'` | '2차 · 장소·시간 추후 공지' |
| `rsvpDeadline` | `'2026-09-30'` | 마감일 문구 없이 표시 |
| `hostContact` | `'홍길동 · 010-1234-5678'` | 문의 문구 숨김 |
| `apiUrl` | Apps Script 웹 앱 `/exec` 주소 | 응답 전송·관리자 조회 불가 |

**고친 뒤에는 꼭 확인하세요.** 따옴표(`'`)나 줄 끝 쉼표(`,`)가 하나라도 빠지면 설정 전체가 적용되지 않습니다.
올린 뒤 `index.html`과 `rsvp.html`을 열어 바꾼 값이 보이는지 확인합니다.
GitHub Pages는 반영에 1~2분, 휴대폰 캐시 때문에 최대 10분쯤 걸릴 수 있습니다. 급하면 주소 뒤에 `?v=2`처럼 붙여서 열어 보세요.

## 3. GitHub Pages로 배포

Netlify의 폴더 끌어다 놓기 배포는 `.gitignore`를 무시해서 GPS가 든 원본 사진까지 올라가므로 **git으로 올리는 GitHub Pages**를 씁니다.

1. GitHub에서 새 저장소를 만듭니다(Public, 예: `jinwon-farewell`).
2. 이 폴더에서:
   ```bash
   git add .
   git commit -m "송별회 초대장"
   git remote add origin https://github.com/<아이디>/<저장소>.git
   git push -u origin main
   ```
3. 저장소 **Settings > Pages > Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 Save.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`로 접속되는지 확인합니다.

이후 수정은 `git add . && git commit -m "..." && git push`만 하면 됩니다.

### 카카오톡 미리보기 (링크를 처음 공유하기 전에)

카톡은 미리보기를 오래 캐시하므로 **처음 공유하기 전에** 아래를 끝내 두세요.

1. `index.html`의 `<meta property="og:image" content="images/og.jpg">`를 절대 주소로 바꿉니다.
   예: `content="https://<아이디>.github.io/<저장소>/images/og.jpg"`
2. 올린 뒤 카톡 '나와의 채팅'에 링크를 보내 미리보기 카드를 확인합니다.
3. 예전 미리보기가 계속 보이면 <https://developers.kakao.com/tool/clear/og>에서 주소를 넣고 초기화합니다(카카오 로그인 필요).

## 4. 주최자 페이지

- 주소: `https://<사이트 주소>/admin.html`로 열고 **관리자 키(ADMIN_KEY 값)를 입력**합니다.
  - 브라우저가 비밀번호 저장을 제안하면 저장해 두세요. 다음부터 자동으로 채워집니다. 공용 PC에서는 저장하지 마세요.
  - `admin.html?key=<ADMIN_KEY 값>`처럼 주소에 키를 붙여 열어도 됩니다. 이 주소는 **단톡방에 올리지 마세요.**
  - 키가 틀리면 목록이 나오지 않고 다시 입력하라는 안내가 나옵니다.
  - 상단 '초대장 링크 복사'는 키가 빠진 초대장 주소를 복사합니다.
- **카톡 인앱 브라우저가 아닌 일반 브라우저**(PC Chrome, 휴대폰 Safari/Chrome)로 여세요. 카톡 안에서는 CSV 다운로드가 되지 않습니다.
- 숫자는 페이지를 열 때의 시트 내용입니다. 새 응답을 보려면 새로고침하세요.

## 5. 배포 후 휴대폰 확인 체크리스트

초대장 주소를 카톡 **'나와의 채팅'**으로 보내고, iPhone 1대와 Android 1대의 **카톡 인앱 브라우저**에서 확인합니다.

- [ ] 미리보기 카드(제목·설명·사진)가 제대로 뜬다
- [ ] D-day가 보이고, 사진 4장이 스크롤할 때 위에서 내려오며 나타난다
- [ ] '주소 복사', '링크 복사' 후 채팅 입력창에 붙여넣으면 내용이 들어간다
- [ ] '공유하기'를 누르면 공유창이 뜨거나(iPhone) 링크가 복사된다(Android 카톡)
- [ ] 지도 영역이 보인다(`mapEmbedUrl`을 넣은 경우), '지도 앱으로 보기'가 열린다
- [ ] 이름을 '테스트'로, 참석 + 함께해요로 제출 → 완료 화면 요약이 맞다
- [ ] 완료 화면에서 뒤로 가기 → 다시 제출할 수 있다(버튼이 '보내는 중…'에 멈춰 있지 않다)
- [ ] 응답 페이지를 다시 열면 이전 값이 채워져 있다 → 불참으로 바꿔 제출 → 시트에 '테스트' 행이 **하나**이고, second가 비어 있고, updatedAt이 바뀌었다
- [ ] '캘린더에 추가'를 누르면 외부 브라우저에서 구글 캘린더 일정 화면이 열린다
- [ ] 한마디 입력 중 키보드가 올라와도 하단 '응답 보내기' 바가 글을 가리지 않고, 입력창을 눌렀을 때 화면이 확대되지 않는다
- [ ] 주최자 페이지를 올바른 키로 열면 숫자가 시트와 같고, 틀린 키로 열면 '관리자 키가 올바르지 않습니다.'가 나온다
- [ ] iPhone Safari, Android Chrome에서도 제출 → 완료를 한 번씩 해 본다
- [ ] **끝나면 시트에서 테스트 행을 지운다**

## 알아둘 점

- **같은 이름 = 같은 사람**입니다. 같은 이름(공백·대소문자 무시)으로 다시 내면 새 행 대신 기존 응답이 수정됩니다. 동명이인은 이름 뒤에 구분 표시를 붙여 달라고 안내하세요(예: `김민수B`).
- **캘린더**는 구글 캘린더에만 추가됩니다. 시작 시간이 정해지기 전에 추가한 일정은 종일 일정으로 남으니, 시간이 정해지면 다시 추가하라고 안내하세요. 카톡에서는 외부 브라우저로 열리도록 해 두었는데, 안 열리면 '다른 브라우저로 열기'를 쓰면 됩니다.
- 응답은 이 브라우저에 기억됩니다. 다른 기기에서 수정할 때는 같은 이름으로 다시 내면 됩니다.
